# Economic Evaluation of RAG and Fine-Tuning Architectures

This repository contains a simulation framework for evaluating the economic efficiency of Retrieval-Augmented Generation (RAG) and Fine-tuning architectures in corporate analytics systems based on large language models.

## Structure

- run_experiment.py – main simulation script
- plot_results.py – generates figures for the article
- config.yaml – experiment configuration
- results/ – generated outputs

## Reproducibility

To reproduce the experiment:

```bash
python run_experiment.py
python plot_results.py
